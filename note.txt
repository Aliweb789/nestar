| Decorator | Purpose |
|---|---|
| `@Module()` | Groups providers, controllers, and imports |
| `@Injectable()` | Allows Nest to create and inject a class |
| `@Controller()` | Defines a REST controller |
| `@Get()` | Defines a REST GET endpoint |
| `@Resolver()` | Defines a GraphQL resolver |
| `@Query()` | Defines a GraphQL query |
| `@Mutation()` | Defines a GraphQL mutation |
| `@Args()` | Reads GraphQL arguments |
| `@InputType()` | Defines GraphQL input |
| `@ObjectType()` | Defines GraphQL output |
| `@Field()` | Exposes a property in GraphQL |
| `@UseGuards()` | Runs a guard before the resolver |
| `@InjectModel()` | Injects a Mongoose model |
| `@IsNotEmpty()` | Requires a nonempty input |
| `@Length()` | Validates string length |
